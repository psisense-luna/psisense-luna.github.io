01 / THE TECHNOLOGYCurrent architecture · Legacy V7

The signal matters.
So does what came before.

TCR-H extracts neurophysiological descriptors from EEG and ECG. A causal, multiscale memory contextualizes each epoch using the available history of the same case.

The reference research pipeline uses two EEG channels at 128 Hz, ECG and 30-second epochs. Five domain-specific models are trained and frozen.

Read the evaluation protocol +

Matched comparison

TCR and BIS are compared on the same selected epochs. V8 observed BIS is oriented as 100 − BIS. Counts per domain overlap and must not be added as unique patients.

Two views of AUC

Global AUC pools epochs across cases. Within-case AUC evaluates discrimination separately in each case and gives every case equal weight.

Causal features, retrospective labels

History is built chronologically. Inference does not receive dose, BIS or labels. High/low labels are defined using the full case exposure distribution (q25/q75).

Scope of inference

Confidence intervals resample patients. Prior exploratory development and multiple comparisons are not included in those intervals. Independent-source and prospective validation remain next steps.
