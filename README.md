# PsiSense Luna — GitHub Pages

Website for Samuel Santos Oliveira da Silva.

## Publish

Copy the files in this package into the root of `psisense-luna/psisense-luna.github.io`, retaining the `assets` folder. Replace the existing `index.html`. Commit to `main`.

In **Settings → Pages**, select **Deploy from a branch**, then **main / (root)** if it is not already configured. The site address is https://psisense-luna.github.io/ .

No build tools or server are required. `.nojekyll` keeps this a plain static site.

## Files

- `index.html`, `styles.css`, `app.js`: page, design and interactions.
- `assets/landscape.jpg`: Luca Micheli / Unsplash landscape supplied by Samuel.
- `assets/favicon.svg`: site icon.
- `assets/evidence.json`: exact V7/V8 evidence shown on the site.

The causal-memory demo is synthetic and performs no medical inference. Research evidence was transcribed from the supplied `TCR_H_LIVE_FINAL_V7/RESULTADOS_CONGELADOS.md`. Model files, raw patient data and confidential commercial documents are not included.

Portuguese/English switch, interactive benchmark tabs, CSV downloads and layered photo background are preserved.
